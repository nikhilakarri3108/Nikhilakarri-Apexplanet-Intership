The vulnerability assessment of the Metasploitable2 virtual machine showed that the system is intentionally insecure and contains several critical as well as high-risk weaknesses. The purpose of the scan was to identify exploitable services, outdated applications, and unsafe configurations present on the host. A full vulnerability scanner was used to inspect the open ports and exposed services. The results confirmed that the machine has multiple serious security flaws that could easily be used by attackers.

One of the most critical findings was the presence of **vsftpd 2.3.4**, a well-known vulnerable FTP server version containing a backdoor that may allow unauthorized root access. Another major issue was **UnrealIRCd 3.2.8.1**, which is associated with a backdoor vulnerability capable of remote command execution. The scan also detected weaknesses in the **Apache Tomcat/AJP service**, where outdated components may expose the server to remote attacks and code execution. The recommended solution for these vulnerabilities is to upgrade or replace the affected software with secure and updated versions.

Several high-severity issues were also identified during the scan. The **MySQL** database service was running an outdated release that may contain authentication and privilege escalation flaws. The **Apache HTTP Server** version detected on port 80 is also old and may be affected by known web server vulnerabilities such as information leakage and denial-of-service attacks. The **Telnet** service running on port 23 presents a serious security risk because all communication, including usernames and passwords, is transmitted without encryption. In addition, the **Samba** service was found to be vulnerable to older remote exploitation techniques that may allow unauthorized system access. The recommended remediation includes updating all services, disabling unused ports, and replacing insecure protocols such as Telnet with SSH.

In conclusion, the vulnerability scan clearly demonstrates that Metasploitable2 contains multiple severe weaknesses and outdated services, making it highly exposed to compromise. Important recommendations include applying security patches, removing unnecessary services, using encrypted communication methods, and configuring firewall protections to strengthen overall system security.
